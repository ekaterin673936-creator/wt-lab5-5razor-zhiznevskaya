## Описание

Веб-приложение на ASP.NET Core Razor Pages для управления автопарком.

**Функционал:**
- Список автомобилей (Bootstrap-каталог)
- Просмотр подробной информации
- Добавление нового автомобиля
- Редактирование

URL появится после деплоя на Render
